# Full Stack Engineer Assignment:

## Frontend Assignment:

- Instructions:

  >Open the campaign-creation folder

  1. Install the dependencies:
     ```bash
     npm install 
     ```
  2. Start the Frontend Application:
     ```bash
     npm run dev
     ```
 ## Backend Assignment:

   1. Navigate to the api-backend directory.
      ```bash
      cd api-backend
      ```
   2. Create a virtual environment:
      - Windows:
        ```bash
        python -m venv .venv
        ```
      - Mac or Linux:
        ```bash
        python3 -m venv .venv
        ```  
   3. Activate the virtual environment:
      - Windows:
        ```bash
        .venv\Scripts\activate
        ```
      - Mac or Linux:
        ```bash
        source .venv\bin\activate
        ```
   4. Install the dependencies from the requirement.txt
      ```bash
      pip install -r requirements.txt
      ```
   5. To start the API backend:
      ```bash
      flask --app main run
      ```
